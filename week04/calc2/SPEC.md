# 계산기 프로젝트 명세서 (SPEC.md)

## 1. 개요
본 프로젝트는 사칙연산 및 우선순위를 지원하는 계산기 모듈(`calc.py`)과 이를 검증하기 위한 단위 테스트(`test_calc.py`)를 구현하는 것을 목표로 한다.

## 2. 요구사항 (Requirements)
1. **기본 사칙연산**: 덧셈(`+`), 뺄셈(`-`), 곱셈(`*`), 나눗셈(`/`)을 지원한다.
2. **연산자 우선순위**: 곱셈과 나눗셈은 덧셈과 뺄셈보다 먼저 계산되어야 한다.
3. **괄호 처리**: 괄호 `(`와 `)`를 지원하며, 괄호 안의 수식을 최우선으로 계산한다.
4. **음수 및 소수점 처리**: 음수(예: `-5`) 및 소수점(예: `3.14`) 연산을 올바르게 처리한다.
5. **예외 처리**: 0으로 나누기 시도(`ZeroDivisionError`) 및 잘못된 수식 입력 시 적절한 예외를 발생시킨다.

## 3. 구현 모듈 (`calc.py`)
- `calculate(expression: str) -> float | int`
  - 문자열 형태의 수식을 입력받아 계산 결과를 반환한다.
  - 예: `calculate("2 + 3 * 4")` -> `14`

## 4. 테스트 모듈 (`test_calc.py`)
- Python의 `unittest` 프레임워크를 사용한다.
- 최소 20개 이상의 다양한 테스트 케이스(기본 연산, 우선순위, 괄호, 소수점, 음수, 예외 처리 등)를 포함하여 작성한다.
