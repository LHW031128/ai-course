# 주차 요금 계산기 스펙

## 1. 개요
입차·출차 시각을 넣으면 요금을 계산해 목록에 쌓고, 오늘 받은 요금 합계를 보여 주는 창 하나짜리 프로그램.
Python 3 + tkinter, 표준 라이브러리만 사용한다.

## 2. 파일 구성
- SPEC.md: 이 문서 (동작 규칙, 테스트 표)
- parking_calc.py: 계산 로직만. tkinter, print, input을 쓰지 않는다
- test_parking_calc.py: 테스트. 실행하면 통과/실패 수를 출력한다
- parking_app.py: tkinter 화면. 계산은 parking_calc의 함수만 사용한다
- 실행: python week08/test_parking_calc.py, python week08/parking_app.py

## 3. 시각 입력 규칙
- 24시간제 "시:분". 시는 1~2자리(0~23), 분은 2자리(00~59). 예: 09:30, 9:30
- 앞뒤 공백은 무시한다
- 목록에는 항상 두 자리로 표시한다 (9:05 → 09:05)
- 빈 입력과 형식 오류(0930, ab:cd, 24:00, 12:60 등)는 오류로 처리한다
- 출차는 입차보다 늦어야 한다. 같거나 빠르면 오류
- 자정을 넘기는 주차(예: 23:00 → 01:00)는 지원하지 않는다. 같은 날 안에서만 계산하며, 순서 오류로 처리한다

## 4. 요금 규칙
- 주차 시간(분) = 출차 − 입차
- 30분 이하: 0원
- 30분 초과: 초과분을 10분 단위로 올림한 횟수 × 500원. 정수로 계산한다: (초과분 + 9) // 10
- 한 건(차 한 대)의 요금은 최대 20,000원이다 (430분부터 20,000원). 합계에는 상한이 없다

## 5. 목록과 합계
- 계산에 성공하면 목록에 한 줄 추가: 입차 | 출차 | 주차 시간 | 요금 | [삭제]
- 주차 시간 표시: 60분 미만은 "45분", 나누어떨어지면 "1시간", 그 외는 "1시간 35분"
- 금액 표시: 천 단위 쉼표 + "원" (예: 1,500원, 20,000원)
- [삭제]를 누르면 그 줄만 지우고 합계를 다시 계산한다 (확인 창 없음)
- 창 아래에 "오늘 합계: 24,000원 (3건)" 형식으로 표시한다
- 목록은 프로그램이 켜져 있는 동안만 유지한다 (파일 저장 안 함)

## 6. 오류 처리
- 오류가 나면 목록에 추가하지 않고, 입력칸 아래에 빨간 글씨로 메시지를 보여 준다 (팝업 없음)
- 검사 순서: 입차 빈 값 → 입차 형식 → 출차 빈 값 → 출차 형식 → 출차가 입차보다 늦은지
- 메시지
  - 빈 입력: "입차 시각을 입력하세요." / "출차 시각을 입력하세요."
  - 형식 오류: "입차 시각이 올바르지 않습니다. 00:00~23:59 사이로 입력하세요. (예: 09:30)" (출차는 "출차 시각이 ...")
  - 순서 오류: "출차 시각은 입차 시각보다 늦어야 합니다. (자정을 넘긴 주차는 계산하지 않습니다)"
- 계산에 성공하면 입력칸과 메시지를 비우고 입차 칸에 커서를 둔다. Enter 키로도 계산한다

## 7. 함수 (parking_calc.py)
- parse_time(text, label) → 자정부터의 분(int). label은 "입차"/"출차". 빈 값·형식 오류면 ValueError
- calc_fee(minutes) → 요금(int)
- format_duration(minutes) → "1시간 35분" 같은 문자열
- format_won(amount) → "1,500원" 같은 문자열
- make_record(entry_text, exit_text) → {"entry": "09:30", "exit": "11:05", "minutes": 95, "fee": 3500}. 오류면 ValueError
- total_fee(fees) → 요금 리스트의 합계(int)
