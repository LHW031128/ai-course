## 4. 원리적 한계 실험 기록 (직접 해보기 8)

### 환각(Hallucination) 유도
- **가짜 논문 질문:** '양자 어텐션 네트워크' 논문이 실제 존재하지 않음에도 불구하고 양자 컴퓨팅과 딥러닝 결합 메커니즘을 적용했다며 서술을 지어냄.
- **가짜 파이썬 함수 질문:** `listx.flatten_deep()`에 대해 "표준 라이브러리에 없는 함수"라고 맞혔으나, `more_itertools` 패키지에 존재한다는 가짜 설명을 덧붙임.

### 지식 컷오프(Knowledge Cutoff)
- **2024 노벨 물리학상:** 가상의 인물 이름(루이스 엘리엇 등)을 지어내며 환각 발생. (실제: 존 홉필드, 제프리 힌턴)
- **2025 노벨 물리학상:** 모델 훈련 시점 이후이므로 "발표되지 않았다"고 판단.

### 온도(Temperature) 변화
- **temperature=0:** 3회 모두 똑같은 답변 출력.
- **temperature=1.5:** 매 실행마다 3가지 답변이 서로 다른 단어 조합으로 무작위하게 생성됨.

## 5. 컨텍스트 오버플로우 분석 (직접 해보기 9)

- **오버플로우 시작 지점:** `num_ctx=2048` 설정 시 반복 60회(2,797자) 지점에서 비밀번호 인지 불가.
