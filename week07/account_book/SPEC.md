# 용돈 기입장 스펙

내용, 금액, 수입과 지출 구분을 넣어 목록에 쌓고, 수입 합계, 지출 합계, 잔액을 보여 주는 창 하나짜리 프로그램이다.

## 1. 기술과 파일 구성

### 기술

- Python 3.10 이상, Flet 1.0. 다른 패키지는 쓰지 않는다. 파이썬에 들어 있는 모듈(random, json 등)은 쓸 수 있다.
- Flet은 1.0에서 문법이 크게 바뀌었다. 아래 코드는 화면 파일 `main.py`의 시작 코드(뼈대)이고, Flet 1.0에서 동작을 확인한 것이다. `main.py`는 이 뼈대를 그대로 가져와 넓혀서 만든다. 계산 파일 `logic.py`에는 뼈대가 없고 처음부터 만든다.
- 뼈대에 나온 Flet 문법만 쓴다. 뼈대에 없는 Flet 클래스, 인자, 속성은 쓰지 않는다. 기억하고 있는 Flet 문법은 옛 버전의 것이므로 쓰지 않는다.
- 특히 다음은 Flet 1.0에 없으므로 쓰면 오류가 난다: `ft.app(...)`, `ft.colors`, `ft.alignment.center`, `ft.ElevatedButton`, `Button(text=...)`, `page.window_width`, `ft.UserControl`, `TextField(error_text=...)`

```python
# main.py
import flet as ft


def main(page: ft.Page):
    page.title = "예제"
    page.window.width = 360
    page.window.height = 440
    page.window.resizable = False

    value = ft.TextField(label="값", value="", width=150)
    unit = ft.Dropdown(label="단위", value="cm", width=120,
                       options=[ft.dropdown.Option("cm"), ft.dropdown.Option("m")])
    upper = ft.Checkbox(label="대문자 포함", value=True)
    result = ft.Text(value="", size=20, weight=ft.FontWeight.BOLD)
    notice = ft.Text(value="", color=ft.Colors.RED)
    items = ft.ListView(expand=True, spacing=4)

    def on_run(e):
        notice.value = ""
        if not value.value.strip():
            notice.value = "값을 입력합니다"
        else:
            result.value = f"{value.value} {unit.value}, 대문자 {upper.value}"
            items.controls.append(ft.Row(controls=[
                ft.Text(value=result.value, expand=True),
                ft.Button(content="삭제", data=len(items.controls), on_click=on_delete),
            ]))
        page.update()

    def on_delete(e):
        items.controls.pop(e.control.data)     # 버튼을 만들 때 data에 넣어 둔 번호
        for i, row in enumerate(items.controls):
            row.controls[1].data = i
        page.update()

    page.add(
        ft.Row(controls=[value, unit]),
        upper,
        ft.Button(content="실행", on_click=on_run, expand=True, height=44,
                  bgcolor=ft.Colors.BLUE, color=ft.Colors.WHITE),
        result,
        notice,
        items,
    )


ft.run(main)
```

### 파일 구성

| 파일 | 내용 |
|---|---|
| `SPEC.md` | 스펙 |
| `logic.py` | 계산과 판정. Flet을 import하지 않는다. 입력을 받아 결과를 돌려주는 함수만 있다 |
| `main.py` | 화면. 뼈대를 넓힌 것. 계산은 전부 `logic.py`의 함수를 불러서 한다 |
| `test_logic.py` | `logic.py`의 함수를 검사한다. 실행하면 통과와 실패 수를 출력한다 |

잘못된 입력의 처리도 `logic.py`에서 한다. 함수가 `None`이나 안내 문구를 돌려주고, `main.py`는 그것을 화면에 보여 주기만 한다.

## 2. 동작 규칙

### 2.1 기록

- 기록 한 건은 구분, 내용, 금액 세 가지를 가진다. `logic.py`에서는 `{"kind": "지출", "memo": "점심", "amount": 8000}` 모양의 dict로 다룬다.
- 기록 목록은 이 dict의 list다. 새 기록은 맨 뒤에 붙는다. 화면에서는 추가한 순서대로 위에서 아래로 보인다.
- 같은 내용을 두 번 넣으면 두 줄로 쌓인다. 합치지 않는다.
- 프로그램을 끄면 기록은 사라진다.

### 2.2 구분

- 수입과 지출 두 가지다. 프로그램을 켰을 때 고른 값은 지출이다.
- 두 가지가 아닌 값이면 추가하지 않고 "구분을 고릅니다"를 보여 준다.

### 2.3 내용

- 앞뒤 공백을 자르고 저장한다.
- 자른 뒤 비어 있으면 내용을 "(내용 없음)"으로 해서 추가한다. 내용 때문에 추가가 막히는 일은 없다.
- 글자 수는 제한하지 않는다.

### 2.4 금액

- 0보다 큰 정수여야 한다.
- 앞뒤 공백과 쉼표를 모두 지운 뒤 0부터 9까지의 숫자만 남아야 한다. 쉼표의 위치는 따지지 않는다. `1,000`, ` 1000 `, `10,00`은 모두 1000이다.
- 앞에 0이 붙은 숫자는 그 값으로 받는다. `0500`은 500이다.
- 소수점, 부호, 글자, 숫자 사이의 공백이 있으면 받지 않는다. `1000.0`, `-500`, `+500`, `천원`, `1 000`은 모두 받지 않는다.
- 상한은 두지 않는다. 아무리 큰 수도 받는다. 파이썬은 4300자리가 넘는 정수를 글자와 서로 바꾸지 못하게 막아 두므로, `logic.py`가 시작할 때 이 제한을 푼다.

| 금액 칸 | 결과 |
|---|---|
| 비어 있거나 공백뿐 | 추가하지 않는다. "금액을 입력합니다" |
| 그 밖의 잘못된 값 (0, 소수, 음수, 글자 등) | 추가하지 않는다. "금액은 0보다 큰 정수로 입력합니다" |

### 2.5 추가

- 검사는 구분, 금액 순서로 한다. 먼저 걸린 것의 안내 문구 하나만 보여 준다.
- 성공하면 기록을 목록 맨 아래에 붙이고, 합계와 잔액을 다시 계산하고, 안내 문구를 지우고, 내용 칸과 금액 칸을 비운다. 구분은 고른 그대로 둔다.
- 실패하면 목록, 합계, 잔액, 입력 칸을 그대로 두고 안내 문구만 보여 준다.

### 2.6 삭제

- 목록의 각 줄에 삭제 버튼이 있다. 누르면 확인을 묻지 않고 그 줄만 지운다.
- 지우면 합계와 잔액을 다시 계산하고 안내 문구를 지운다.
- 없는 줄 번호로 지우라고 하면 목록을 그대로 둔다.

### 2.7 합계와 잔액

- 수입 합계는 구분이 수입인 기록의 금액을 더한 값이다.
- 지출 합계는 구분이 지출인 기록의 금액을 더한 값이다.
- 잔액은 수입 합계에서 지출 합계를 뺀 값이다. 음수가 될 수 있다.
- 목록이 비어 있으면 셋 다 0이다.

### 2.8 금액 표시

- 천 단위마다 쉼표를 넣고 뒤에 "원"을 붙인다. 1234567은 `1,234,567원`, 0은 `0원`, -5000은 `-5,000원`이다.
- 목록의 줄에서는 금액 앞에 부호를 붙인다. 수입은 `+50,000원`, 지출은 `-8,000원`이다.
- 색: 목록의 금액은 수입이 파랑, 지출이 빨강이다. 수입 합계는 파랑, 지출 합계는 빨강이다. 잔액은 0 이상이면 파랑, 음수면 빨강이다.

### 2.9 logic.py의 함수

| 함수 | 받는 것 | 돌려주는 것 |
|---|---|---|
| `parse_amount(text)` | 금액 칸의 글자 | 정수. 2.4에 맞지 않으면 `None` |
| `clean_memo(text)` | 내용 칸의 글자 | 앞뒤 공백을 자른 내용. 비어 있으면 `"(내용 없음)"` |
| `add_entry(entries, kind, memo, amount_text)` | 기록 목록과 입력 세 가지 | `(새 목록, 안내 문구)`. 성공하면 안내 문구가 `""`, 실패하면 목록이 그대로 |
| `remove_entry(entries, index)` | 기록 목록과 줄 번호(0부터) | 그 줄을 뺀 새 목록 |
| `totals(entries)` | 기록 목록 | `(수입 합계, 지출 합계, 잔액)` |
| `format_won(amount)` | 정수 | `"1,234원"` 모양의 글자 |
| `format_signed(kind, amount)` | 구분과 금액 | `"+1,234원"` 또는 `"-1,234원"` |
| `is_minus(amount)` | 정수 | 음수면 `True`. 잔액 색을 정할 때 쓴다 |

함수는 받은 목록을 고치지 않고 새 목록을 돌려준다.
