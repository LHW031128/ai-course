## 2. 미니 검색기 테스트 (search.py)
- **Q: "시험 언제야?"** -> `0.600 기말고사는 12월 셋째 주에 실시한다`
- **Q: "책 빌리는 곳 몇 시에 닫아?"** -> `0.701 도서관은 평일 오전 9시부터 오후 10시까지 연다`
- **Q: "학교 그만두려면 어떻게 해?"** -> `0.563 휴학 신청은 학과 사무실에서 서류를 받아 제출한다`

## 3. 어텐션(Attention) 쉬운 설명 (비전공자용)
어텐션은 문장을 처리할 때 중요한 단어에 집중해서 무게를 주는 인공지능 기술입니다. 사람이 글을 읽을 때 관련 깊은 단어에 더 눈길을 주듯, AI도 "사과를 깎아 먹었다"에서 '깎아'를 처리할 때 '사과'라는 단어를 더 높은 가중치로 바라봅니다. 문장이 길어져도 필요한 정보를 놓치지 않게 도와주는 핵심 원리입니다.
